## 证据边界与剩余操作

- S02 使用 no-store 请求和响应、页面/扩展 CacheStorage 与 IndexedDB 枚举、local/sessionStorage 枚举、特定缓存目录的合成明文标记扫描，以及服务端真实重取计数。明文扫描不能证明任意压缩/编码格式都已解码检查。
- 去掉 Playwright 默认禁用 BFCache 的参数后，真实历史返回仍为 `pageshow.persisted=false`；CDP 报告 no-store 资源和 browsing instance 原因。普通历史返回已验证；实际 BFCache 命中未验证。T10 的显式 pagehide/pageshow 事件测试单独记录，没有用合成事件冒充真实命中，也未降低缓存安全策略。
- 品牌浏览器检查时 Mac 锁定，原生应用不可操作，`/Applications` 未发现 Edge；这反映该次环境检查，不假定用户电脑始终锁定。用户在可操作环境按 M01/M06/M07 装载扩展、验证核心操作和真实中文/日文组合输入后，另加 `manual/run-003`，再作 acceptance-002。
- 三站点均为 synthetic dummy，未证实公司 SSO、真实 Jira/MM 权限、实际 Mattermost 版本或生产网络。计划内的生产包演练只访问 loopback 与示例 Host。
- 共享看板无账户系统，任何被网络允许访问者均可读写共享内容。生产须由公司内网/VPN及 HTTPS 代理限制访问，数据库在 release 外持久化且只运行单实例。
