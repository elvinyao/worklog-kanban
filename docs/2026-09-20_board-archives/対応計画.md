# 首页预览与归档实施计划

用户已明确要求「帮我实装这个方案」，作为已呈现设计的实施授权，不重复申请同一范围的许可。沿用 main inline、本地 commit、不 push；所有运行通过 `.agent/run.sh`。Python 3.13.15、Node 24.21.0、FastAPI/React/TypeScript 及既有锁定依赖不变，无新增依赖。已有未提交文件仅为上一轮本主题的设计与演示。

## T01 预览开关

修改 App、Board、CardDialog、i18n/messages、styles；浏览器布尔偏好 `worklog.cardPreviews`，未设置默认 false。资源集合为开启的首页卡片与当前详情的并集；关闭清理、取消、释放头像，保留限流冷却。复用现有 PreviewStore。补充浏览器用例证明默认无外部读取、详情单卡读取、关闭资源释放、刷新偏好保持；已有预览用例显式开启。

验证：相关现有基线、预览开关浏览器 RED → GREEN、层级/隐私/生命周期浏览器回归。记录结果后提交局部成果。

## T02 归档数据与接口

修改 schema/store/schemas/api/events/errors/validation，新增 archives.py。v1/v2→v3 自动 SQLite backup 后单事务迁移，is_done 为显式列标记。新增严格共享快照、归档摘要、请求去重、恢复来源表。归档请求包含 requestId、expectedBoardRevision、cardIds、name/description；同请求重放不新建/不发布 SSE；异参同键 409。恢复生成所有新 ID、重验源站 URL、保留遗留消息、一个归档条目最多一个活动副本。元信息 expectedMetadataVersion；列表时间+ID分页、名称/说明搜索。删除 Current 卡前记下归档来源，旧编辑/移动返回 archived 及 archiveId。

验证：先写并跑失败用例，覆盖快照不可变、范围/排序/层级、事务失败回滚、重放/最新 revision、并发写入和恢复、跨页搜索、迁移保留/备份、非法输入与错误边界；生成 API 类型，运行全后端与类型检查。每个真实写事务只递增一次全局 revision。

## T03 归档界面

新增归档列表、确认/重命名/恢复对话框、只读卡片详情；App 增加 hash 路由和列表状态保留，Board 增加 readOnly（阻止拖拽、键盘移动、编辑与新建）。完成列管理支持 isDone。归档选中/保留数量明确、冲突重新核对、失败保留草稿且同请求重试。恢复有目标列和来源活动副本提示。远程归档时保留 CardDialog 基准/草稿，禁止旧保存，提供查看归档/复制草稿。三语言齐备。

验证：浏览器 RED → GREEN，覆盖归档到列表再返回、恢复不重复、只读、默认关闭预览、完成列配置、异步冲突、远程归档草稿保护、列表搜索、窄屏和中英日。资源仅对应当前看板与打开详情。

## T04 自查、验收与部署

按设计逐项核对，独立只读审阅数据/生命周期；修复发现的问题后只重跑受影响检查。完整后端/前端/浏览器回归及 StrictMode 关键用例、build/check。补充运行说明、v3 回退与备份说明。部署前读取共享数据计数，`app update --local` 保留卷更新，确认迁移备份、健康状态与数据保留。完成证据和本地提交；不操作用户真实任务做归档试验。
