# 用户指导

## 首次使用真实服务

1. 打开管理员提供的看板地址。创建卡片、共享笔记、关联和列管理无需浏览器扩展。
2. 下载管理员提供的、与当前部署对应的扩展 artifact 并解压。Chrome / Edge 的扩展管理页开启开发人员模式，选择“加载已解压的扩展”，选包含 manifest.json 的 `extension` 目录。受管浏览器由管理员按公司策略安装。
3. 点击扩展图标核对看板、Jira、Mattermost 三个地址；按提示允许站点权限。需要修改时保存设置，再刷新目标看板。
4. 在同一浏览器 profile 中正常登录真实 Jira 和 Mattermost，再回看板读取预览。不要把密码、Cookie 或 Token 填进看板或扩展地址设置。

设置只影响当前浏览器，不修改服务器。三组地址必须与目标看板一致；“恢复部署默认”清除个人地址覆盖。扩展更新后重新加载扩展并刷新看板，原个人覆盖值仍保留。

## 看板与关联

创建卡片后可编辑标题、纯文本笔记，拖动排序或跨列移动。卡片详情添加 Jira 编号或票据 URL，再在对应 Jira 下添加 Mattermost 单条消息链接。每卡最多 20 张 Jira，每 Jira 最多 20 条消息，每卡总计最多 100 条消息。可调整顺序、移动消息归属；移除 Jira 会连带移除其消息关联，不删除原系统内容。无 Jira 的普通卡片也可保存。

管理列可设置完成列；删除列需选择接收卡片的列。多人编辑冲突时保留草稿，核对最新共享内容后再保存。正在改名的列被他人删除时，未保存列名仍可复制，直到明确丢弃。编辑窗口可显式勾选保存本机草稿（在当前浏览器 origin 内保留七天，最多 20 份），刷新后重新打开对应窗口可选择“恢复草稿”，也可在页脚“本机草稿”查看、复制或删除；未勾选时草稿仅保留在当前页面内存，离开前自行保留需要的内容。

卡片、列名和归档表单有未保存修改时，关闭、切换页面或刷新会提示确认。保存等待超过 15 秒会结束等待并保留输入；这时服务器仍可能已保存。新建卡片若提示结果不明，请在原对话框点击“重试并确认创建结果”，会确认同一次创建，不产生重复卡片；确认前暂时锁定输入。

方向键选择卡片，Alt+左右移至邻列，Enter 打开，Esc 关闭；输入框内仍正常编辑。首页右上角可选自动/中文/EN/日本語，不改变用户文本或原系统内容。

## 个人预览

首页默认关闭“卡片预览”；开启后显示 Jira 和下挂消息。详情也可读取预览，可刷新全部或单个资源。没有定时外部轮询。登录失效/无权限时清除正文，网络失败可能保留本页结果并标记旧内容。

每人只看到自己源站权限允许的内容。预览仅在当前页内存，离开页面清除，不写入共享服务器；手动复制到共享笔记的内容会对其他看板用户可见。图片不自动加载，原文链接可直接打开。

Jira 评论读取过慢或页数过多时先显示摘要，并提示评论暂未取得；可打开原文查看。Mattermost 附加信息读取超时仍显示已取得的正文，作者、频道或头像可能暂缺。

## 归档

在列管理标记完成列，使用“归档已完成任务”选择任务、填写名称说明并确认。Archives 支持搜索、更多加载及重命名；归档保留当时共享内容，不可直接编辑。预览仍读取源站当前内容，不是历史正文快照。

“恢复任务”在选定列创建副本并保留原归档；已有 Current 副本不能重复恢复。任务被他人归档时，旧编辑草稿保留，需复制草稿或查看归档。网络断开、保存结果不明时在原对话框重试，避免重复操作。

## 排错

| 现象 | 处理 |
| --- | --- |
| 扩展未连接 | 核对安装目录、站点权限，重新加载扩展并刷新页面 |
| 扩展设置读取失败 | 点击“重试加载”；成功后再编辑或恢复默认，避免覆盖尚未读取的设置 |
| 地址与看板不一致 | 对照管理员提供的三个地址修改；设置不能改服务器 |
| 提示登录或无权限 | 同 profile 打开源系统登录、确认资源权限，再刷新预览 |
| 站点证书或网络错误 | 确认浏览器的公司代理/CA；容器设置不能修复浏览器连接 |
| 旧内容或限流 | 等待提示时间后手动刷新 |
| 共享保存冲突 | 比较当前内容与草稿，再决定保存 |
| 更新/恢复后显示异常 | 刷新全部看板标签页并使用对应扩展 |

只有演练环境才登录 fake 的 Alice/Bob。fake 登录页和真实账号不是一回事；生产用户不需要启动任何模拟服务。
